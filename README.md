# NHS Professionals Shift Exception Management Demo

This repository demonstrates how GitHub Copilot can support Power Platform delivery for a realistic NHS Professionals workforce operations scenario.

## Scenario

Operations coordinators need a way to identify, triage, and escalate bank shift exceptions before they create operational risk.

## Demo Flow

1. Use a Product Manager agent to create Azure Boards work items.
2. Use GitHub Copilot to generate Power Platform solution design.
3. Create Dataverse table design and sample data.
4. Generate Power Fx formulas for the canvas app.
5. Generate Power Automate flow design.
6. Review the solution for security, accessibility, and ALM readiness.

## Technology Areas

- GitHub Copilot
- Azure Boards via ADO MCP
- Power Apps
- Dataverse
- Power Fx
- Power Automate
- Power Platform ALM
